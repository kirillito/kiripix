# The Manifest decides what export may overwrite

Kiripix overwrites a file in the Godot project only if the Manifest lists it and the file's current hash matches the
recorded one. The `; generated by kiripix` header stays, but only as a hint for humans: PNGs cannot carry it, and
saving a generated scene in the Godot editor may drop it. A hash mismatch means someone edited the file, so export
refuses and names it. `--force` backs up and overwrites a mismatched file; `--adopt` backs up and takes over an
unmanaged file already at the target path. `export --dry-run` lists the two cases separately. Godot's `.import`
sidecars are ignored.

## Consequences

- The Manifest lives only in the Godot project, under the export root, and is committed with the game, so it always
  matches the files on the game's current branch. Any local copy in `.kiripix/` is a cache, never the authority. Without
  the game repo at the configured path, export and the ID freeze checks refuse rather than guess.
- Every ID the Manifest records (Asset, Marker, Layer, clip, node names derived from Masks) is frozen once exported:
  adding IDs is fine; renaming or removing one is refused. Before the first export, IDs can be renamed freely.
- Files of a deleted Asset are removed only by an explicit `export --prune`, under the same hash rule and backup.
- The Manifest is one file per Asset, so unrelated Assets never conflict in git. Same-Asset conflicts are resolved by a
  `kiripix manifest merge` driver: the higher counter plus one, the union of the IDs, our `files` with theirs recorded in
  `replacing`, so the next export accepts either. Export checks for the driver in each clone, and its finding's `fix` is
  `kiripix manifest install`, which puts `.gitattributes` under `<root>/manifest/` and sets the local git config.
  `kiripix manifest repair` is the fallback for a Manifest with conflict markers, for example after a conflict on
  GitHub, which never runs the driver.
- Each Asset entry carries a counter that goes up when its exported hash changes; the Manifest carries a schema version
  and the Kiripix version that wrote it.
